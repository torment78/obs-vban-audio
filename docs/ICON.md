# Project artwork

The product is **VBAN Stream by ElkaSoft**, an independent plugin for OBS Studio.

## Icon

Asset: `data/vban-audio.png`. Used by the plugin's settings window.

`installer/vban-audio.ico` contains the same artwork at 16, 24, 32, 48, 64, 128
and 256 pixels for Windows. It is generated by
`tools/create-installer-icon.ps1` during installer packaging. Setup, Uninstall
and the Windows Installed apps entry use this icon. The product-name change
does not alter either icon file.

The icon was generated with the built-in imagegen tool: a cyan audio waveform
between two amber endpoint nodes, surrounded by cyan return arrows on a dark
background. It contains no lettering.

## Banners and social preview

[View and download all eight variants](ARTWORK.md).

Two background styles are available: straight circuit lines and waves with
circuit lines. Each has horizontal and vertical versions with and without the
small VoiceMeeter / VB-Audio credit. Every banner reads **VBAN Stream**, retains
**by ElkaSoft**, and keeps **Windows x64 | OBS Studio** as the compatibility line.

The README uses [images/social-preview.jpg](images/social-preview.jpg):
**1774 × 887 pixels, 214,474 bytes**. All JPEGs are under 1 MB, at
the same dimensions as their PNG originals. JPEG quality is 92.

To change the image shown when the GitHub repository link is shared:

1. Open the repository's **Settings** tab.
2. Under **Social preview**, choose **Edit → Upload an image**.
3. Select your preferred horizontal JPEG from the artwork gallery.

This setting is separate from the README image. Sites such as Discord may cache
an older preview for a while after it changes.

[GitHub social-preview documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)

The [editing prompts](ARTWORK-PROMPTS.md) record the title change and the
additional waves variants. The artwork uses the repository's GPL-2.0-or-later
license.
